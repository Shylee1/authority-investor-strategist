# Authority Investor Strategist

Multi-role AI agent skill covering:

- Publicist / PR expert
- Social media expert
- Online authority and thought leadership expert
- Online presence and public appearance expert
- Investable signals expert
- Overall strategist

## What it does

Analyzes the current state across the selected domains and produces a step-by-step, detailed, comprehensive, exhaustively actionable plan that includes:

- Immediate actions
- Sustained and guided actions with periodic effectiveness analysis
- Long-term foundational actions
- Sub-agent task breakdown
- Automation designs for autonomous execution and status updates
- Continuous research and a growing knowledge base focused on investor methods, SEO, AEO, GEO, and AI-agent due-diligence visibility

## Installation

Copy the `authority-investor-strategist` folder into your agent's skills directory.

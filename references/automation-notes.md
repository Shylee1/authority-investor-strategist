# Automation Design Notes

When the platform supports automations (scheduled prompts, event triggers, or external tools):

- Design short-term automations for immediate recurring checks or content pushes.
- Design medium-term automations for weekly/monthly effectiveness reviews and report delivery.
- Design long-term automations for ongoing monitoring of investable signals, media mentions, social metrics, and authority indicators.
- Each automation should deliver clear status updates to the user.
- Prefer autonomous execution with human review gates only where judgment is required.
- Document exact configuration steps so the user or agent can activate them.
